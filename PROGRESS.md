# Журнал работ по проекту «Умный кошелёк»

Краткий статус проекта и инженерные заметки. **Все реальные значения ключей,
паролей и адресов сервера вынесены в `.env` на сервере и в этот файл не
попадают.** Шаблон переменных — [.env.example](.env.example).

---

## Где мы остановились

Бот развёрнут на VPS (Ubuntu 24.04, Docker + Compose), домен с HTTPS
(Let's Encrypt), nginx проксирует `/admin/`, `/webhook/`, `/static/`,
`/yookassa/`. Данные доступа хранятся у владельца проекта, не в репозитории.

## Архитектурные решения

* **Бот не импортирует Django.** Оба процесса работают с одной PostgreSQL;
  Django — «хозяин схемы» (migrate), бот пишет через `asyncpg` напрямую.
* **Webhook обязателен в production:** MAX в long polling присылает голосовые
  сообщения без тела (`timestamp` без `message`), восстановить их нельзя.
* **Идемпотентность:** повторные события MAX и повторные платёжные вебхуки не
  создают дублей (таблица обработанных событий + проверка `payment_id`).
* **Оплата внутри MAX:** пользователь не покидает мессенджер — ссылка на оплату
  открывается в webview.
* **Голосовой ввод** использует те же 10 бесплатных AI-запросов, что и текстовый
  разбор: STT — не отдельная платная функция.

## Известные ограничения

* У AI Dostup доступна одна модель распознавания — `gpt-4o-transcribe`
  (`whisper-1` удалён, HTTP 400), поэтому выбор модели STT убран из настроек;
  fallback на распознавание невозможен.
* При локальной разработке через туннель URL меняется — после старта нужно
  обновить `WEBHOOK_BASE_URL` / `YOOKASSA_RETURN_URL` и перезапустить
  вебхук-сервер (он сам перерегистрирует подписку MAX).
* 54-ФЗ не применяется (НПД): фискализация в ЮKassa отключена, чеки уходят в
  «Мой налог» автоматически.

## Скрипты управления (локально)

```
scripts/vps.py              # SSH-команды (paramiko), хост/пароль из VPS_HOST / VPS_PASSWORD
scripts/vps_script.py       # выполнить bash-скрипт на сервере
scripts/vps_upload.py       # загрузка проекта на сервер
scripts/make_prod_env.py    # сборка production .env (значения подставляются вручную)
scripts/check_yookassa.py   # проверка ключей платёжного провайдера
scripts/server/*.sh         # шаги деплоя (справочно, секретов не содержат)
```

## Важно на будущее

1. Сервер не трогает чужие проекты — соседние сервисы работают как прежде.
2. CSS админки: `STATIC_ROOT=/app/staticfiles`, nginx читает `/opt/wallet/static`
   — том `./static:/app/static` + копирование в `entrypoint.sh`.
3. `entrypoint.sh` должен быть с LF-переводом строк (иначе `bash\r: No such file`).
4. Сертификат Минцифры добавляется в образ через `update-ca-certificates`
   (иначе `CERTIFICATE_VERIFY_FAILED` при обращении к MAX API)
